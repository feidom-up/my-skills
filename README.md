# my-skills

Personal [Claude Code](https://claude.com/claude-code) skills.

| Skill | What it does |
|---|---|
| [web-load-perf-playbook](skills/web-load-perf-playbook/SKILL.md) | Six-phase playbook for diagnosing slow first load, choosing a rendering architecture, cutting startup bytes, measuring honestly and migrating traffic gradually. Distilled from X Engineering's "Rebuilding the global town square from scratch" (2026-11-04). |
| [ai-ambition](skills/ai-ambition/SKILL.md) | Upgrades an ordinary AI request along three axes: Altitude (outcome over task), Depth (expert standard with an outside judge) and Range (a cross-field crew). Distilled from Felix Rieseberg's "How to be more ambitious: A tutorial for humans with models". |

## Install

Copy a skill directory into `~/.claude/skills/`:

```bash
cp -r skills/web-load-perf-playbook ~/.claude/skills/
```
